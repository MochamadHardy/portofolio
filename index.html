About Me

Dedikasi dalam Menciptakan Solusi Digital Terbaik

Menggabungkan logika backend yang kokoh dengan pengalaman pengguna (UX) yang mulus di sisi client.

Halo! Saya seorang Fullstack Developer yang berfokus pada arsitektur sistem scalable, otomasi data, dan aplikasi dunia nyata (real-world applications).

Dalam setiap proyek, saya mengawali rancangan dari fondasi yang kokoh: markup semantik HTML5, styling terstruktur dengan CSS3 & Bootstrap, serta version control disiplin dengan Git & GitHub.

Di sisi backend, saya menguasai ekosistem PHP (Laravel) dan Python (Flask) untuk merancang RESTful API modular serta pengelolaan database relasional seperti PostgreSQL dan MySQL. Di sisi frontend, saya menghadirkan antarmuka dinamis dan reaktif menggunakan Vue.js serta modern JavaScript (ES6+), memastikan performa cepat dan pengalaman pengguna yang optimal.
